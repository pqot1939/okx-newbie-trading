# OKX 新手教學：從註冊、身份驗證到現貨買賣，先搞懂入金、手續費與風險

第一次接觸 OKX，最容易卡住的地方通常不是「怎麼按下買入」，而是前面的幾個基本問題：要不要先完成身份驗證？買入 USDT 後為什麼不能直接交易？市價單和限價單有什麼差別？邀請碼該在哪裡填？手續費又是怎麼算？

這篇 OKX 新手教學會按照實際使用順序，帶你完成註冊、身份認證、入金、買幣、資金劃轉和現貨交易，也會整理 OKX 目前公開的交易費率等級。先從現貨開始比較適合新手，合約、槓桿和期權則放到後面再研究，否則很容易還沒搞懂保證金，就先把風險放大了。

> OKX 的服務、產品和交易權限會因所在地區而不同。註冊前應先確認你的居住地是否支援相關服務，並閱讀平台當下顯示的條款與風險提示。

## OKX 是什麼？新手先分清交易所和錢包

OKX 是提供數位資產交易與相關服務的平台，主要功能包括現貨交易、合約交易、快捷買幣、資產轉入轉出、賺幣、Web3 錢包和其他鏈上工具。對剛入門的人來說，最需要先理解的是「交易所帳戶」和「Web3 錢包」不是同一回事。

交易所帳戶比較像平台內的交易帳戶。你可以在裡面買賣 BTC、ETH、USDT 等資產，使用現貨或其他交易功能。Web3 錢包則是用來連接區塊鏈、管理私鑰和操作鏈上應用。兩者的操作風險不同，轉帳時也不能把交易所地址和錢包地址混為一談。

如果你的目標只是買入比特幣、以太幣或 USDT，先從 OKX 的交易所帳戶和現貨交易開始就夠了。不要一註冊就急著研究所有功能，介面上的按鈕很多，但不代表每個按鈕都適合第一天使用。

### 註冊時常見的三個問題

**邀請碼之後可以補填嗎？**
不要假設可以。部分活動要求在註冊時綁定邀請關係，之後再輸入可能不會生效。最穩妥的做法是在提交註冊前確認邀請碼欄位。

**可以只用電子郵件註冊嗎？**
實際要求可能按地區和帳戶流程不同。OKX 的官方註冊說明同時提到電子郵件、手機號碼和驗證碼流程，應以你當下看到的註冊頁面為準。

**註冊後能立即買幣嗎？**
通常不能跳過身份驗證。OKX 官方買幣教學明確寫明，首次購買數位資產的新手需要先完成身份驗證，再使用快捷買幣功能。

## 身份驗證怎麼做？為什麼一定要完成 KYC？

完成身份驗證後，平台才能根據你的所在地、帳戶狀態和產品資格開放相應功能。驗證內容通常包括個人資料、證件資料和人臉辨識等步驟，實際項目會按照所在地區和平台要求顯示。

在 App 中，一般可以按照以下路徑尋找：

**個人中心 → 帳戶或身份認證 → 立即認證**

準備資料時，注意幾件小事：

- 使用本人有效證件，不要借用他人資料。
- 證件照片要清晰，四角盡量完整入鏡。
- 姓名、生日和居住地資料要與證件一致。
- 人臉辨識時不要使用過度濾鏡或遮擋臉部。
- 只在 OKX 官方 App 或官方頁面提交資料，不要把證件傳給所謂的客服或代辦人。

身份驗證完成後，部分帳戶還可能需要額外完成風險評估或其他帳戶設定。OKX 官方新手指南提到，完成認證可以解鎖相應交易權限，而不同認證等級也可能對充幣、提幣等功能設有不同限制。

## 入金方式：快捷買幣、銀行轉帳和鏈上轉入

完成身份驗證後，你需要把資金放入 OKX，才可以開始交易。常見方式大致分為三類：

### 1. 快捷買幣

快捷買幣適合想直接使用信用卡、金融卡或其他支援支付方式購買數位資產的人。官方操作流程是先選擇幣種和金額，再選擇支付方式，最後按照頁面提示付款。

常見流程：

1. 點擊「買幣」或「購買／充值」。
2. 選擇「快捷買幣」。
3. 選擇 BTC、ETH、USDT 等資產。
4. 輸入法幣金額或幣的數量。
5. 選擇付款方式。
6. 確認報價、手續費和實際到帳數量。
7. 完成付款並等待資產到帳。

快捷買幣的顯示價格可能已經包含支付服務商費用或價差，所以不要只比較交易頁面的交易費率，也要查看最後付款金額和實際收到的資產數量。信用卡交易若失敗，官方說明指出通常不會扣款，但不同發卡銀行的授權結果可能不同。

### 2. 銀行轉帳或當地支付方式

部分地區可能支援銀行轉帳或其他法幣通道。這種方式通常要先完成身份驗證，並按照帳戶所在地的支付規則操作。

這裡最重要的是確認：

- 收款人名稱是否與平台頁面一致。
- 轉帳備註是否需要填寫指定內容。
- 支付方式是否支援你的所在地。
- 報價是否包含服務費。
- 付款後是否需要回到 App 點擊「已付款」。

不要私下向任何人轉帳，也不要相信社群裡提供的「低價代充」或「人工加速到帳」。C2C 交易需要按照平台訂單流程付款，不要脫離訂單直接轉帳。OKX 官方新手指南也提醒，進行 C2C 買幣前應閱讀平台交易規則。

### 3. 從其他交易所或錢包鏈上轉入

如果你已經在其他交易所或錢包持有 USDT、BTC 或 ETH，也可以使用充值地址轉入 OKX。

操作時務必同時確認：

- 幣種一致。
- 網路一致，例如 Ethereum、TRON、BSC 等。
- 充值地址完整無誤。
- 是否需要填寫 Memo、Tag 或備註。
- 最低充值數量。
- 該資產是否支援你選擇的網路。

例如，你選擇 USDT-TRC20，提幣端也必須選擇相同網路。幣種和網路不匹配，資產可能延遲到帳，甚至需要聯絡客服處理，並不一定能找回。

## USDT 到帳後，為什麼還不能直接交易？

這是 OKX 新手最常遇到的問題之一。

OKX 的帳戶通常會區分資金帳戶和交易帳戶。買入或充值的資產可能先進入資金帳戶；要進行現貨交易，則需要把資產劃轉到交易帳戶。官方現貨教學也把「資金劃轉」列為交易前的必要步驟。

App 端一般流程：

**資產 → 資金劃轉 → 選擇 USDT → 從資金帳戶到交易帳戶 → 輸入數量 → 確認**

這通常只是帳戶內部的資金移動，不是把幣提到鏈上，也不需要輸入外部錢包地址。看到「從資金帳戶到交易帳戶」時，不用把它理解成區塊鏈轉帳。

## OKX 現貨交易教學：用 BTC/USDT 做例子

現貨交易就是用一種資產買入另一種資產。例如 BTC/USDT 代表以 USDT 買賣 BTC，BTC 是交易標的，USDT 是計價資產。OKX 官方說明，目前現貨交易頁面會按不同交易區顯示交易對，例如 USDT、USDⓈ 和 Crypto 交易區。

### 買入流程

1. 進入「交易」。
2. 選擇「現貨」。
3. 搜尋 `BTC/USDT`。
4. 選擇「買入」。
5. 選擇限價委託或市價委託。
6. 輸入買入價格和數量，或輸入預計使用的 USDT 金額。
7. 確認委託內容。
8. 查看訂單是否成交。

### 賣出流程

1. 進入 `BTC/USDT` 現貨交易頁面。
2. 選擇「賣出」。
3. 選擇限價委託或市價委託。
4. 輸入價格和數量。
5. 提交訂單。
6. 在目前委託或歷史委託中查看成交狀態。

OKX 官方現貨教學提到，常用的委託方式包括限價委託和市價委託，也提供止盈止損、計劃委託等其他類型。

### 市價單和限價單有什麼差別？

**市價委託**：按照當前市場可成交價格盡快成交。優點是速度快，缺點是實際成交價格可能和下單時看到的價格有差異，特別是在市場波動大或深度不足時。

**限價委託**：你自己設定願意接受的價格。只有市場價格達到條件，訂單才會成交。優點是價格可控，缺點是可能一直不成交。

新手第一次操作時，可以先用很小的金額測試，確認自己看得懂交易對、買賣方向、數量和手續費，再逐步增加金額。不要因為頁面上的 K 線突然上漲，就直接用全部資金追價。

## OKX 手續費怎麼算？

OKX 的交易手續費不是固定月費，也不是買一個「基本套餐」就能永久使用。平台通常按照帳戶等級、交易產品、交易對分組以及你是掛單方還是吃單方計算。

簡單理解：

- **掛單方 Maker**：委託沒有立即成交，而是先進入訂單簿等待撮合。
- **吃單方 Taker**：委託直接與訂單簿中已有掛單成交。
- 市價單通常較容易成為吃單。
- 限價單不一定都是掛單，若立即與現有訂單成交，也可能按吃單費率計算。

OKX 官方說明，手續費取決於實際成交方式，不單純取決於你按的是市價單還是限價單。普通用戶的標準現貨費率為掛單 0.2000%、吃單 0.3500%，但具體費率仍應以帳戶當下顯示為準。

例如使用普通用戶費率，買入價值 1,000 USDT 的資產，若按 0.3500% 計算，交易費約為 3.5 USDT。實際扣除的幣種和金額，會按平台對該交易對的規則處理，這只是方便理解的示例，不代表所有交易對都使用相同費率。

## 新手該先買幣，還是直接做合約？

如果你還不熟悉以下概念：

- 現貨和合約的差別
- 保證金
- 槓桿倍數
- 強平價格
- 資金費率
- 止損和止盈
- 倉位大小
- 未實現盈虧

那麼先不要把合約當成入門工具。

現貨交易最多通常是持有的資產價格下跌；合約則可能因為槓桿讓損益被放大，價格短時間反向波動就可能觸發強制平倉。這不是「交易速度更快」這麼簡單，而是風險結構不同。

比較合理的學習順序是：

1. 先完成註冊和身份驗證。
2. 用小額資金了解入金和提幣。
3. 學會資金帳戶與交易帳戶的劃轉。
4. 使用現貨交易認識限價單、市價單和成交紀錄。
5. 先用模擬交易熟悉合約介面。
6. 只有在理解保證金和強平機制後，才考慮是否使用槓桿。

OKX 官方註冊說明提到，平台提供模擬交易模式，讓新手可以使用測試資產練習交易流程。這種功能適合用來熟悉介面，但模擬交易不會完全重現真實市場中的心理壓力、滑點和資金損失。

## 提幣和資產安全：新手最不能省略的設定

完成交易後，很多人會忽略帳戶安全，直到收到異常登入通知才開始補救。註冊後建議立即檢查以下設定：

### 開啟雙重身份驗證

優先使用身份驗證器或平台支援的安全驗證方式。不要把驗證碼、登入密碼、API 金鑰或私鑰交給任何人。

### 設定反釣魚碼

如果平台提供反釣魚碼，可以設定一段只有你和平台知道的識別文字。收到郵件或通知時，先確認內容是否出現正確的反釣魚碼。

### 提幣前做小額測試

第一次向新地址提幣時，先轉一筆小額測試。確認網路、地址和到帳情況都正確後，再處理剩餘資產。

### 確認地址和網路

提幣頁面的地址看起來很長，人工比對容易漏字。可以使用複製貼上，但貼上後仍要檢查開頭、結尾和網路名稱。剪貼簿被惡意程式修改時，直接貼上也可能把資產送到錯誤地址。

### 不要開啟不理解的 API 權限

如果只是一般買幣和現貨交易，通常不需要建立 API。需要使用 API 時，應關閉提幣權限，只開啟真正需要的讀取或交易權限。

## OKX 新手常見錯誤

### 把「充值」和「交易」混在一起

充值只是把資產轉入帳戶，交易則是買賣資產。充值 USDT 不代表已經買入 BTC，還要進入相應交易對下單。

### 沒有看清楚交易對

BTC/USDT、BTC/USDC 和 BTC/USD 並不是完全相同的交易對。下單前先確認計價資產和可用餘額。

### 把限價單當成保證成交

限價單只有在市場價格符合條件時才會成交。訂單一直掛著，不代表平台出錯。

### 只看幣價，不看手續費和滑點

資產價格相同時，實際收到的數量仍可能因交易費、支付服務費、價差和滑點而不同。快捷買幣頁面的最終確認畫面尤其要看清楚。

### 把所有資金放進單一高風險交易

新手常見的問題不是不會按按鈕，而是一次投入過多資金。即使使用現貨，也應先設定可承受的資金範圍，不要使用影響日常生活的錢交易。

## OKX 新手教學的實際操作順序

如果你只想知道從零開始應該怎麼做，可以按照這個順序：

1. 透過 [👉 CASH20 邀請連結註冊 OKX](https://okx.com/join/CASH20)。
2. 輸入並確認邀請碼 `CASH20`。
3. 完成電子郵件、手機號碼和身份驗證。
4. 開啟雙重身份驗證。
5. 先查看買幣頁面的報價、支付方式和費用。
6. 以小額方式買入 USDT 或其他你已經了解的資產。
7. 確認資產位於哪個帳戶。
8. 將需要交易的資產劃轉到交易帳戶。
9. 進入現貨頁面，先熟悉交易對和訂單欄位。
10. 用小額限價單測試買入，再查看歷史委託和手續費。
11. 需要提幣時，先核對地址、網路和最低提幣數量。
12. 暫時不要急著使用槓桿、合約或高風險理財產品。

OKX 的功能很多，但新手真正需要掌握的核心流程其實很短：**註冊、驗證、入金、劃轉、現貨下單、查看費用和保護帳戶**。把這幾步弄清楚，再研究其他產品，學習成本會低很多，也比較不容易因為一個看不懂的按鈕付出昂貴代價。
